# Let's Gamble!

A Minecraft mod for **Fabric 1.20.1** that brings a full gambling system to the game. Put your items on the line, where your winning odds scale dynamically based on the relative value of what you're betting.

---

## Features

* **Quick Access:** Press **G** anytime to trigger the gambling interface (fully rebindable in settings).
* **Smart Valuation:** An item-value system that automatically calculates fair winning probabilities based on the wager.
* **Secure Networking:** Built with clean client/server packet synchronization to ensure safe inventory management and fair payouts.

---

## Tech Stack

* **Game Version:** `1.20.1`
* **Mod Loader:** Fabric Loader
* **Language:** Java 17
* **Dependencies:** Fabric API
